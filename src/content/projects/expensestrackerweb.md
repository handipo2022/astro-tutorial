# 🪙 AI-Powered Expenses Tracker

A modern, full-stack web application designed to help users seamlessly track, filter, and analyze their financial data. With secure authentication, smart categorization, and advanced AI integration, managing personal finances has never been easier.

## ✨ Features

### 👤 User Authentication

- **Secure Signup:** Create new user accounts with encrypted credentials and upload profile's picture from a image file or shot by webcam
- **User Login:** Secure authentication to protect personal financial data.
- **Session Management:** Persistent login sessions with secure logout functionality.
- **Edit Profile:** Existing user can update profile.

### 💰 Transaction Management

- **Income Tracking:** Log various income sources with amounts, dates, and descriptions.
- **Expense Tracking:** Record daily expenses quickly with dedicated categories.
- **Receipt Scanner (OCR):** Upload or take a photo of a receipt to automatically extract and populate expense details.

<p align="center">
  <img src="/images/readme_img_exp_tracker/receipt_ocr.png" alt="Receipt Scanner Interface" width="300" style="max-width: 100%; border-radius: 8px; box-shadow: 0 4px 8px rgba(0,0,0,0.1);"/>
</p>

### 🔍 Smart Filtering

- **Category Filter:** Sort income and expenses by specific categories (e.g., Food, Utilities, Salary).
- **Date Range Filter:** View transactions within specific days, weeks, months, or custom ranges.

<p align="center">

</p>

### 🤖 AI Financial Insights

- **Automated Analysis:** AI processes your transaction history to spot spending trends.
- **Smart Budgeting Advice:** Receive personalized recommendations to optimize your savings.
- **Anomalies Detection:** Get alerted by the AI about unusual or spiking expenses.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JSON Web Tokens (JWT)
- **AI & OCR Execution:** Google GenAI, Tesseract.js (or Cloud Vision API)
